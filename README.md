# 💰 Extrato de Gastos

Aplicação desktop desenvolvida em **Java**, para controle simples de entradas e saídas financeiras. O objetivo é oferecer uma interface gráfica amigável para registrar e visualizar movimentações, simulando um extrato pessoal.

## 📋 Funcionalidades

- ✅ Registro de entradas e saídas de dinheiro  
- 🖊️ Campos para descrição, valor e tipo de transação  
- 📅 Exibição das movimentações em lista  
- 💵 Cálculo automático e exibição do saldo atual  
- 🧠 Armazenamento em memória (sem banco de dados)

## 🛠️ Tecnologias Utilizadas

- Java  
- IDE: IntelliJ IDEA

## 🖼️ Interface

A aplicação contém:

- Um formulário principal com:
- Campo para digitar valor, descrição e tipo de transação (entrada ou saída)
- Botão para adicionar o gasto
- Lista exibindo as transações realizadas
- Exibição do saldo total atualizado em tempo real

## 📈 Melhorias Futuras

- Implementar armazenamento em arquivo ou banco de dados
- Permitir exportação do extrato em PDF ou CSV
- Adicionar filtros por data
- Adicionar gráficos de análise dos gastos

ℹ️ Este projeto não utiliza banco de dados. Todos os dados ficam em memória enquanto o app estiver aberto.
